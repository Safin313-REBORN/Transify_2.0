# Transify — Bangladesh Sign Language (BdSL) Sign Verification Registry
## 10-Class MVP Communicative Expression Specification

**Document Version:** 2.0.0  
**Phase:** Phase 2 — Sign Language Recognition Module  
**Linguistic Standards Authority:** Bangladesh National Federation of the Deaf (BNFD), National Foundation for Development of the Disabled Persons (JPUF), Ministry of Social Welfare (MoSW) *Bangla Sign Language Dictionary*, and Centre for Disability in Development (CDD).

---

## 1. Scope and Linguistic Verification Mandate

Transify strictly prohibits the invention or synthetic improvisation of sign language gestures based on literal English word translations. Sign languages possess autonomous phonological, morphological, and syntactic structures.

This registry documents the verified, authentic Bangladesh Sign Language (BdSL) equivalent for each of the 10 predefined closed-vocabulary communicative expressions. Every entry details:
1. **Phonological Parameters:** Handshape (configuration), location (place of articulation), orientation (palm facing), and movement (path, dynamics).
2. **Grammatical Modality:** Single-handed versus two-handed articulation.
3. **Non-Manual Markers (NMMs):** Linguistically obligatory facial expressions, head movements, and mouth morphemes.
4. **Disambiguation Rules:** Boundaries preventing misclassification with phonologically adjacent gestures.

## 2. Exhaustive 10-Class BdSL Linguistic Registry

### Class 0: `HELLO`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `HELLO` |
| **Bengali Gloss / Term** | হ্যালো / শুভেচ্ছা / সালাম / নমস্কার (`HELLO` / `GREETINGS`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary*, Ministry of Social Welfare (MoSW) & JPUF; UNDP BdSL E-Dictionary; BRAC BdSL Tutorial Series. |
| **Dominant Handshape** | **Open Flat Palm (B-Handshape):** Fingers extended straight and adducted (held together); thumb rested alongside index finger. |
| **Non-Dominant Hand** | Inactive (rested at side or waist level). |
| **Location (Place of Articulation)** | Starts at ipsilateral side of forehead / temple (or upper chest level in informal registers). |
| **Palm Orientation** | Palm faces outward toward the conversational partner; fingertips point upward. |
| **Movement Trajectory** | Hand moves outward and forward in a polite, smooth arc away from the temple toward the recipient. In casual discourse, a gentle lateral 2-cycle wave ($5\text{ cm}$ oscillation) is accepted. |
| **Dynamics & Deceleration** | Moderate tempo, smooth deceleration without abrupt jerk. |
| **Non-Manual Markers (NMM)** | Obligatory friendly eye contact; slight forward head nod; polite facial smile. |
| **Linguistic Structure** | Single lexical sign. |
| **Regional / Stylistic Variations** | In formal Islamic Deaf communities, a traditional right-hand salute from forehead with inward touch is used; in general secular/youth communities, the open-palm forward salute/wave dominates. Both are supported via spatial normalization. |
| **Disambiguation Boundaries** | Must not be confused with `STOP` (which starts forward with abrupt stopping deceleration at chest height) or ASL 'B' fingerspelling (which is static). |

### Class 1: `THANK_YOU`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `THANK_YOU` |
| **Bengali Gloss / Term** | ধন্যবাদ (`DHONNOBAD` / `THANK YOU`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF, Section: Courtesy Signs); CDD Sign Resource Portal. |
| **Dominant Handshape** | **Flat Hand (B-Handshape or Flat-O):** Fingers straight and held closely together; thumb relaxed. |
| **Non-Dominant Hand** | Inactive. |
| **Location (Place of Articulation)** | Starts touching or positioned within $2\text{ cm}$ of the chin / lower lip. |
| **Palm Orientation** | Palm faces inward toward the signer's face at initiation; turns slightly upward/outward as it extends forward. |
| **Movement Trajectory** | Originates at chin level; moves smoothly downward and outward in an arc extending toward the addressee ($20–30\text{ cm}$ path). |
| **Dynamics & Deceleration** | Fluid, grateful arc with gentle release. |
| **Non-Manual Markers (NMM)** | Respectful head bow (slight forward incline of $\sim 10^\circ$); warm facial expression with eye contact. |
| **Linguistic Structure** | Single lexical sign. |
| **Regional / Stylistic Variations** | Two-handed variant: Non-dominant hand placed flat under dominant elbow; primarily used in formal or inter-generational address. |
| **Disambiguation Boundaries** | Must not be confused with eating signs (which repeatedly touch lips without extending forward) or `PLEASE` (which is circular on the chest). |

### Class 2: `YOURE_WELCOME`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `YOURE_WELCOME` |
| **Bengali Gloss / Term** | স্বাগতম / কিছু না / ঠিক আছে (`SWAGOTOM` / `KICHHU NA` / `NOT AT ALL`) |
| **Primary Reference Source** | BNFD Conversational BdSL Lexicon; MoSW *Bangla Sign Language Dictionary*. |
| **Dominant Handshape** | **Open Curved Palm (5-Handshape or C-Handshape):** Fingers softly extended, open and relaxed. |
| **Non-Dominant Hand** | Active. Symmetrical open palm mirroring the dominant hand. |
| **Location (Place of Articulation)** | Lower chest / upper abdomen level in front of the body. |
| **Palm Orientation** | Both palms face upward toward the sky; fingertips point slightly forward/outward. |
| **Movement Trajectory** | Both hands move in unison from a forward neutral position inward toward the signer's torso in a sweeping, hospitable motion, or a gentle outward offering sweep indicating "it was nothing, you are welcome". |
| **Dynamics & Deceleration** | Soft, welcoming, relaxed deceleration. |
| **Non-Manual Markers (NMM)** | Sincere, open facial expression; slight head nod; relaxed shoulder posture. |
| **Linguistic Structure** | Single sign or compound ("স্বাগতম" or "কিছু না"). |
| **Regional / Stylistic Variations** | Single-handed casual variant: Right hand sweeps outward from chest with open palm. |
| **Disambiguation Boundaries** | Must not be confused with `PLEASE` (which touches the chest in a circular path) or `I_NEED_HELP` (where fist rests on open palm). |

### Class 3: `PLEASE`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `PLEASE` |
| **Bengali Gloss / Term** | দয়া করে / অনুগ্রহ করে (`DOYA KORE` / `PLEASE`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF); CDD Inclusive Education Training Material. |
| **Dominant Handshape** | **Flat Palm (B-Handshape):** Fingers extended, held together; thumb pressed lightly against index edge. |
| **Non-Dominant Hand** | Inactive. |
| **Location (Place of Articulation)** | Center of the chest over the sternum. |
| **Palm Orientation** | Palm faces flat against the body, maintaining light contact or hovering $1\text{ cm}$ above the chest. |
| **Movement Trajectory** | Moves in a continuous clockwise circular motion ($10–15\text{ cm}$ diameter) across the chest, typically completing 2 full cycles. |
| **Dynamics & Deceleration** | Smooth, steady, rhythmic circular motion. |
| **Non-Manual Markers (NMM)** | Earnest, humble facial expression; slight brow softening; head tilted slightly forward. |
| **Linguistic Structure** | Single lexical sign. |
| **Regional / Stylistic Variations** | Two-handed prayer clasp (করজোড়) occasionally observed in religious or highly formal settings; however, the chest-circular sign is the recognized secular standard. |
| **Disambiguation Boundaries** | Distinct from `THANK_YOU` (which begins at the chin and extends forward) and `YES` (which is an oscillating fist). |

### Class 4: `I_NEED_HELP`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `I_NEED_HELP` |
| **Bengali Gloss / Term** | আমার সাহায্য প্রয়োজন / সাহায্য দরকার (`AMAR SAHAJJO PROYOJON` / `HELP ME`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW); SignBD-Word Category: Emergency; CDD Disability Resource Guide. |
| **Dominant Handshape** | **Closed Fist with Extended Thumb (A-Handshape or 10-Handshape):** Closed fist resting upright. |
| **Non-Dominant Hand** | **Flat Base Palm (B-Handshape):** Open palm facing upward at lower chest height. |
| **Location (Place of Articulation)** | Lower chest / abdominal neutral space in front of torso. |
| **Palm Orientation** | Non-dominant palm faces upward; dominant fist rests on top of non-dominant palm with knuckles pointing outward. |
| **Movement Trajectory** | Directional Compound Sign: Both hands, maintaining the "fist-on-palm" configuration, lift upward and pull inward toward the signer's chest ($15–20\text{ cm}$ inward trajectory). |
| **Dynamics & Deceleration** | Firm, urgent lift with deliberate inward movement. |
| **Non-Manual Markers (NMM)** | Obligatory urgent/concerned facial expression; furrowed eyebrows (inquiring/needy marker); slightly parted lips. |
| **Linguistic Structure** | Directional verb sign ("HELP" inflected toward first-person "ME"). |
| **Regional / Stylistic Variations** | Static base without inward pull denotes generic "HELP"; the inward pull specifically denotes "I NEED HELP" (first-person patient). |
| **Disambiguation Boundaries** | Crucially distinct from generic `STOP` (which has no upward lift and features flat palm impact). |

### Class 5: `YES`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `YES` |
| **Bengali Gloss / Term** | হ্যাঁ / জি / সম্মতি (`HAE` / `JI` / `AFFIRMATIVE`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF); BNFD Basic Sign List. |
| **Dominant Handshape** | **Closed Fist (S-Handshape or Fist with relaxed thumb):** Compact fist. |
| **Non-Dominant Hand** | Inactive. |
| **Location (Place of Articulation)** | Mid-chest to shoulder level in neutral signing space. |
| **Palm Orientation** | Knuckles face forward toward camera/addressee; palm surface faces downward/inward. |
| **Movement Trajectory** | Vertical wrist flexion: The fist pivots downward from the wrist in a nodding motion, mimicking the affirmative nod of a head. Typically executes 2 distinct downward cycles ($5–8\text{ cm}$ amplitude). |
| **Dynamics & Deceleration** | Rhythmic, controlled vertical nodding pulses. |
| **Non-Manual Markers (NMM)** | Synchronous affirmative head nod; relaxed, agreeable facial expression. |
| **Linguistic Structure** | Single lexical sign. |
| **Regional / Stylistic Variations** | In some rural regions, index finger nodding or open palm dipping is observed, but the closed-fist wrist nod is the standardized national sign. |
| **Disambiguation Boundaries** | Must not be confused with `NO` (horizontal movement) or letters like BdSL 'মুষ্টি'. |

### Class 6: `NO`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `NO` |
| **Bengali Gloss / Term** | না / অস্বীকৃতি (`NA` / `NEGATIVE`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF); Ishara-Lipi Linguistic Manual. |
| **Dominant Handshape** | **Extended Index Finger (1-Handshape) or Extended Index + Middle (V-Handshape):** Extended finger pointing upward. |
| **Non-Dominant Hand** | Inactive. |
| **Location (Place of Articulation)** | Chest to chin level in neutral signing space. |
| **Palm Orientation** | Palm faces forward toward addressee; fingertip points upward. |
| **Movement Trajectory** | Horizontal lateral oscillation: The hand waves back and forth side-to-side from the wrist/forearm in 2–3 rapid cycles ($10–15\text{ cm}$ total span). |
| **Dynamics & Deceleration** | Crisp, decisive lateral oscillation. |
| **Non-Manual Markers (NMM)** | Obligatory side-to-side head shake (negation marker); slightly furrowed brow; pursed lips. |
| **Linguistic Structure** | Single lexical sign. |
| **Regional / Stylistic Variations** | Two-finger snap variant (index and middle fingers snap shut onto the thumb) is occasionally used in fast conversational BdSL. The lateral wagging index finger is the most universal and robust. |
| **Disambiguation Boundaries** | Clear distinction from `YES` (which is strictly vertical) and `STOP` (which does not oscillate). |

### Class 7: `OKAY`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `OKAY` |
| **Bengali Gloss / Term** | ঠিক আছে / ওকে (`THIK ACHHE` / `OKAY`) |
| **Primary Reference Source** | BNFD Youth & Contemporary Lexicon; MoSW Conversational Register. |
| **Dominant Handshape** | **O-Ring Handshape (F-Handshape / Ok-Sign):** Tip of the thumb touches the tip of the index finger forming a circle; remaining three fingers (middle, ring, pinky) are extended straight upward and fanned. |
| **Non-Dominant Hand** | Inactive. |
| **Location (Place of Articulation)** | Mid-chest to shoulder level in neutral forward space. |
| **Palm Orientation** | Palm faces forward or slightly angled toward the center ($45^\circ$). |
| **Movement Trajectory** | Static hold or subtle forward emphasis tap ($2–3\text{ cm}$ forward nod from the wrist). |
| **Dynamics & Deceleration** | Stable hold with crisp settling. |
| **Non-Manual Markers (NMM)** | Reassuring facial expression, slight affirmative head nod, direct eye contact. |
| **Linguistic Structure** | Single lexical sign / loan gesture assimilated into universal BdSL. |
| **Regional / Stylistic Variations** | Alternative BdSL indigenous sign: Flat hand held horizontally and flipped palm-up ("সব ঠিক"); however, the O-ring sign is universally understood and preferred in communicative tech interfaces. |
| **Disambiguation Boundaries** | Distinct from `NO` (no lateral oscillation) and static alphabet letters (which lack the forward affirmative emphasis). |

### Class 8: `STOP`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `STOP` |
| **Bengali Gloss / Term** | থামো / বন্ধ (`THAMO` / `BONDHO`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF); SignBD-Word Lexicon. |
| **Dominant Handshape** | **Flat Open Palm (B-Handshape):** Fingers straight, held firmly together; thumb held tightly along the index edge. |
| **Non-Dominant Hand** | Optional base palm (flat palm facing up) OR inactive. |
| **Location (Place of Articulation)** | Center chest level, pushing outward toward the conversational partner. |
| **Palm Orientation** | Palm faces directly forward toward the camera / addressee; fingers point straight up. |
| **Movement Trajectory** | Hand thrusts forward firmly and halts abruptly with high deceleration (simulating a barrier or stop signal). In two-handed variant, the dominant vertical palm chops firmly onto the horizontal base palm. |
| **Dynamics & Deceleration** | High-energy deceleration with zero bounce ($t_{\text{settle}} < 50\text{ ms}$). |
| **Non-Manual Markers (NMM)** | Serious, firm facial expression; wide-open eyes; rigid neck/head posture. |
| **Linguistic Structure** | Single lexical imperative sign. |
| **Regional / Stylistic Variations** | Single-handed forward thrust is universal in pedestrian and conversational discourse; two-handed chop is common in formal instructional settings. Both share the characteristic forward open-palm state. |
| **Disambiguation Boundaries** | Must not be confused with `HELLO` (which has a relaxed arc and friendly facial marker) or `PLEASE` (which is circular on the chest). |

### Class 9: `I_DONT_UNDERSTAND`
| Field | Verified Linguistic Specification |
|---|---|
| **English Semantic Label** | `I_DONT_UNDERSTAND` |
| **Bengali Gloss / Term** | বুঝি না / বুঝি নাই (`BUJHI NA` / `NOT UNDERSTOOD`) |
| **Primary Reference Source** | *Bangla Sign Language Dictionary* (MoSW / JPUF, Cognitive Signs Section); CDD Classroom Interaction Guide. |
| **Dominant Handshape** | **Index Pointing Hand (1-Handshape) transitioning to Open Palm (5-Handshape):** Index finger begins near temple, then hand opens outward. |
| **Non-Dominant Hand** | Optional mirror open palm or inactive. |
| **Location (Place of Articulation)** | Starts at temple / forehead level, moves downward and outward to neutral chest level. |
| **Palm Orientation** | Starts facing the temple; transitions to facing upward/outward as the hand sweeps away. |
| **Movement Trajectory** | Compound trajectory: Index finger taps or gestures near temple (sign for "understand / mind"), followed by an outward sweeping flick while turning the palm upward and shaking the hand slightly side-to-side (sign for "negation / absence"). |
| **Dynamics & Deceleration** | Crisp initial gesture followed by an open outward release. |
| **Non-Manual Markers (NMM)** | Obligatory puzzled facial expression: furrowed brow, slightly open or drawn mouth, side-to-side head shake expressing non-comprehension. |
| **Linguistic Structure** | Compound grammatical sign: `[UNDERSTAND]` + `[NEGATION]`. |
| **Regional / Stylistic Variations** | In fast signing, signers simply flick an open palm outward from the temple accompanied by a head shake and shoulder shrug. |
| **Disambiguation Boundaries** | Must not be confused with simple `NO` (which stays at chest height without temple referencing). |
